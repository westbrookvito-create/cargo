# Sub Tracker Bot

Telegram-бот для арбитражника трафика: показывает, сколько подписчиков реально
«дошло» и осталось в канале по каждому рекламному источнику, и считает оплату
по фиксированной цене за подтверждённого подписчика — отдельно по каждому
проекту (каналу).

## Как это работает

1. Вы добавляете бота **администратором** в канал, куда льёте трафик, и даёте
   ему право **«Приглашать пользователей по ссылке»**. Это нужно, чтобы бот
   мог создавать именные трек-ссылки и видеть события входа/выхода подписчиков.
2. Как только бот становится админом канала, он автоматически регистрирует
   этот канал как проект и присылает вам уведомление в личку.
3. В личке с ботом через `/projects` вы:
   - задаёте **цену за подтверждённого подписчика** и валюту;
   - задаёте **срок удержания** (сколько дней подписчик должен продержаться
     в канале, чтобы засчитаться как оплачиваемый — стандартная защита от
     самоотписки/скликивания в CPA);
   - создаёте отдельную **трек-ссылку** под каждый рекламный источник/крео —
     это обычная Telegram invite-ссылка с именем, Telegram сам сообщает боту,
     по какой именно ссылке подписался пользователь.
4. Бот слушает события `chat_member` по каждому каналу и пишет в базу: кто
   подписался, по какой ссылке, когда, и когда (если) вышел.
5. Раз в час фоновая задача проверяет всех подписчиков в статусе «в ожидании»:
   если они всё ещё в канале и срок удержания прошёл — статус меняется на
   «подтверждено» (и именно эти подписчики считаются в сумме к оплате). Если
   подписчик вышел раньше срока — статус «отписался рано», в оплату не входит.
6. `/projects` → выбрать проект → «📊 Статистика» предлагает выбрать период
   (сегодня / вчера / 7 дней / 30 дней / этот месяц / всё время) и показывает
   по каждому источнику: сколько новых подписчиков пришло в этот период и
   сколько из них **подтверждено именно в этот период** (то есть реально
   принесло деньги) — с суммой к оплате. «⬇️ Экспорт CSV» — выгрузка по
   каждому подписчику за всё время, для сверки с рекламной площадкой или
   заказчиком.
7. Прямо в `/projects` есть «📈 Сводка по всем проектам» — та же разбивка по
   периодам, но в виде одной таблицы сразу по всем каналам (новых / подтверждено
   / отписалось рано / заработано), с суммой по каждой валюте отдельно, если
   у проектов разные валюты. «⬇️ Экспорт всех (CSV)» выгружает подписчиков
   сразу по всем проектам в один файл с колонкой проекта.

## Ограничения Telegram, которые стоит знать

- Обновления `chat_member` для чужих пользователей Telegram присылает боту,
  **только если бот — администратор чата**, и только если бот явно
  подписался на них через `allowed_updates` (это уже сделано в коде).
- Именные трек-ссылки видны боту в поле `invite_link.name` события
  `chat_member` — отсюда и берётся привязка к источнику.
- Создавать invite-ссылки от имени канала бот может, только если у него есть
  право `can_invite_users`.

## Установка

```bash
cp .env.example .env
# заполните BOT_TOKEN (от @BotFather) и OWNER_IDS (ваш user id, через запятую можно указать нескольких)
npm install
npm start
```

Или через Docker:

```bash
cp .env.example .env
docker compose up -d --build
```

База — один файл SQLite (`DB_PATH`, по умолчанию `./data/bot.db`), бэкапить —
просто скопировать файл.

## Команды бота (только для владельцев из OWNER_IDS, в личных сообщениях)

- `/start`, `/help` — краткая справка
- `/projects` — список каналов-проектов и меню управления каждым:
  цена за подписчика, валюта, срок удержания, создание трек-ссылок,
  статистика по источникам, экспорт CSV
